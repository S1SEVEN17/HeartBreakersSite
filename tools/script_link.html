Link Torn script

The Heart Breakers Hub script (leaders) - use the Hub from inside Torn

1 · Make a link code

  1. Tap Make link code, then Copy.
  2. In Torn, open the Hub script (its launcher icon) → ⚙ → paste the code → Save.
  3. The code lasts 30 days. Make a new one any time; old ones keep working until they run out.

The code lets the script act as you on the Hub (leaders' data and saves). Keep it to yourself - no Torn key is in it, and it stops working the moment you're no longer a leader.

2 · Lost a device?

Signs out every Hub script you've linked, on every device. Make a new code afterwards.
