Receipt

GitHub token for one-click saving -
With a token saved, Save receipt commits the receipt straight to the archive - nothing to paste. Create a fine-grained token at GitHub → Settings → Developer settings → Fine-grained tokens: Repository access Only select repositories → HeartBreakersLogo, Permissions → Repository → Contents: Read and write. It's stored only in this browser (like your API key).
"Save receipt" opens GitHub with the receipt file filled in - press Commit changes. Within a few minutes the bot draws the receipt, adds it to the members' Payouts archive and posts it to Discord.
